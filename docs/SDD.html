1. Architektúra systému

Aplikácia využíva klient-side MVC architektúru bez backendu. Celá logika beží v prehliadači používateľa. Nie je potrebný server, databáza ani internetové pripojenie (okrem načítania mapových dlaždíc z OpenStreetMap).

Model  –  data.js (statické dáta) + localStorage prehliadača (dynamické dáta)

View    –  index.html, detail.html, admin.html + style.css

Controller –  app.js (domovská stránka), detail.js (detail), admin.js (admin panel)

1.1 Tok dát (Data Flow)

Prehliadač načíta HTML
  └── Načíta leaflet.css, style.css
  └── Spustí leaflet.js, data.js, [app|detail|admin].js
        │
        ├── data.js → globálna premenná "umyvarne" (13 objektov)
        │
        ├── localStorage → recenzie, stavy, problémy, skryté ID
        │
        └── Controller spracuje vstup používateľa
              └── Aktualizuje DOM + Leaflet mapu

4. Popis komponentov

4.1 data.js – Dátová vrstva

Globálna premenná umyvarne obsahuje pole 13 objektov: 8 umyvární zo Slovenska (Bratislava, Košice, Žilina, Nitra, Trnava, Banská Bystrica, Prešov) a 5 z Českej republiky (Praha, Brno, Ostrava, Plzeň, Liberec). Každý objekt má kompletné informácie vrátane GPS, cenníka, vybavenia a platobných metód.

4.2 app.js – Domovská stránka

Životný cyklus po načítaní stránky:

DOMContentLoaded
  ├── initMapa()            → Leaflet mapa, OpenStreetMap dlaždice, markery
  ├── zobrazUmyvarne()      → CSS Grid karty + počet výsledkov
  └── pridajEventListeners()
        ├── input (hľadanie) → filtrujUmyvarne()
        ├── change (mesto)   → filtrujUmyvarne()
        ├── change (typ)     → filtrujUmyvarne()
        ├── click (.filter-btn) → toggle vybavenia → filtrujUmyvarne()
        ├── click #btn-najblizsia → najdiNajblizisie() [Geolocation API]
        └── click #btn-reset  → reset filtrov + mapa na [49.5, 16.5] z=7

Funkcia nacitajVsetkyUmyvarne() spája dáta z data.js a localStorage, pričom odfiltruje ID zo zoznamu umyto_skryte.

4.3 detail.js – Stránka detailu

Životný cyklus:

DOMContentLoaded
  ├── URLSearchParams → id = parseInt(params.get("id"))
  ├── najdiUmyvaren(id)        → hľadá v data.js aj LocalStorage,
  │                              kontroluje umyto_skryte (čierna listina)
  ├── zobrazDetail(umyvaren)   → generuje celý HTML obsah stránky
  ├── initDetailMapa(umyvaren) → Leaflet mini mapa (zoom 15)
  ├── zobrazSchvaleneProblemy(id) → červené ⚠️ varovania hore na stránke
  ├── zobrazRecenzie(id)       → recenzie z LocalStorage
  ├── nastavFormularRecenzia(id)  → submit → unshift → uloženie
  ├── nastavStatusReporter(id)    → Waze status (3 tlačidlá, 180 min TTL)
  └── nastavHlasenieProblemov(id) → uloženie do umyto_nahlasene_problemy

4.4 admin.js – Admin panel

Funkcie:

  • zobrazVsetkyUmyvarne() – zobrazí všetky umyvárne (data.js + LocalStorage), resp. skryté odfiltruje
  • ulozUmyvaren(e) – validuje formulár, uloží do LocalStorage
  • vymazUmyvaren(id) – základné → čierna listina, pridané → vymaže z LocalStorage
  • zobrazNahlaseneProblemy() – renderuje zoznam s tlačidlami podľa stavu
  • vedietOProbleme(id, umyvarenId) – stav → "viem", pridá do schválených
  • opravitProblem(id, umyvarenId) – vymaže z oboch zoznamov
  • zamietnutProblem(id) – vymaže z čakajúcich bez zobrazenia
  • resetDemo() – vymaže všetky kľúče začínajúce na umyto_

5. Kľúčové algoritmy

5.1 Haversine formula (výpočet vzdialenosti)

function vypocitajVzdialenost(lat1, lng1, lat2, lng2) {
  const R = 6371;  // polomer Zeme v km
  const dLat = (lat2 - lat1) * (Math.PI / 180);
  const dLng  = (lng2 - lng1) * (Math.PI / 180);
  const a =
    Math.sin(dLat/2) * Math.sin(dLat/2) +
    Math.cos(lat1 * Math.PI/180) * Math.cos(lat2 * Math.PI/180) *
    Math.sin(dLng/2) * Math.sin(dLng/2);
  return R * 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a));
}

5.2 Filtrovanie (AND logika)

// Všetky podmienky musia platiť súčasne (AND, nie OR)
vsetky.filter(u =>
  u.nazov.toLowerCase().includes(filter.hladanie) &&
  (filter.mesto === "" || u.mesto === filter.mesto) &&
  (filter.typ   === "" || u.typ   === filter.typ) &&
  filter.vybavenie.every(klic => u.vybavenie[klic] === true)
)

function escapeHtml(text) {
  let div = document.createElement("div");
  div.textContent = text;   // prehliadač automaticky escapuje
  return div.innerHTML;     // < > & " sú bezpečne zakódované
